# Nightfall Protocol — Android MVP

Нативный Android survivors-like без внешнего игрового движка. Landscape 16:9, управление виртуальным стиком.

## Сборка

```powershell
./gradlew.bat assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Фактический автономный build-скрипт создаёт `build/NightfallProtocol-debug.apk`.

## Управление

Стик слева. Атаки автоматические. На повышении уровня коснитесь одной из трёх карточек.

## Технический долг MVP

- Персонажи в бою — процедурные billboard-фигуры; портреты используются на выборе героя.
- Звук и виброотклик не включены в первый билд.
- Геометрия боссовых атак упрощена, но атаки и читаемые предупреждения присутствуют.

## Контент версии 0.2

- Семь ролей рядовых врагов: вампиры, зомби, бандиты, агенты Бюро, одержимые, мутанты и боевые дроны.
- Одержимые используют ближний магический импульс и могут взорваться после смерти.
- Мутанты создают ударную волну с отбрасыванием, дроны держат дистанцию.
- В забеге случайно выбираются три босса из четырёх.
- Мех-костюм «Бастион» имеет пулемёт, ракеты, удар, рывок, поле подавления и повреждённую вторую фазу.
- Пользовательская launcher-иконка подключена к обычному и круглому варианту Android.

## Версия 0.3

- Первый production sprite-atlas Амелии, Сэма и Зика с idle, ходьбой и атакой.
- Прозрачный atlas загружается один раз и отрисовывается без покадровых bitmap-аллокаций.
- Исправлена упаковка `classes.dex`; APK проверен установкой и запуском на Android 15.

## Версия 0.4

- Восемь логических направлений взгляда: стороны света и диагонали.
- Во время движения направление берётся из виртуального стика, во время автоатаки — из положения цели.
- После остановки герой сохраняет последнее направление взгляда.
- Для ракурсов используются настоящие фронтальные, профильные и задние спрайты; зеркалирование применяется только к симметричным диагоналям.

## Sprite Factory (0.5)

Визуалы сущностей теперь регистрируются data-driven определениями в `app/src/main/assets/sprite_factory/entities.json`. Общие `SpriteFactory` и `DirectionalSpriteAnimator` поддерживают:

- произвольные animation ID, loop и one-shot;
- 1, 4 или 8 направлений;
- FPS, pivot, scale и sorting offset;
- единый bitmap-кэш без декодирования на каждого моба;
- сброс состояния при возврате сущности в pool;
- JSON-определения вместо gameplay-знаний о конкретных PNG.

Амелия, Сэм и Зик мигрированы на фабрику. Тестовый зомби проходит `move → attack/hit → death → despawn → pooled spawn` через общий animator.

Convention importer:

```powershell
.\tools\import-sprites.ps1 -SourceDirectory .\art\source
```

Формат имени: `entity__animation__8dir__10fps__loop.png`. Строки содержат направления, столбцы — кадры анимации. Importer проверяет размеры, копирует texture в Android resources и обновляет `generated_entities.json`.
